# Security / Безопасность

This tool is for authorized, read-only inspection. It never remediates automatically. Treat findings as leads, not proof. Never upload personal snapshots, executable samples, credentials or unredacted reports to a public issue.

For a vulnerability in this project, contact the repository owner privately or use GitHub private vulnerability reporting if enabled. Include the rule/version, a minimal synthetic example and expected behavior. Do not include actual malware or personal data.

Утилита предназначена для разрешённой проверки только на чтение. Находки — повод для разбора, не окончательный вердикт. Не публикуйте личные снимки состояния, исполняемые образцы, пароли и неочищенные отчёты. Об уязвимости проекта сообщайте владельцу приватно, приложив версию и минимальный вымышленный пример.
